## Project Description
This project will analyze the student social media dataset from Kaggle to evaluate how patterns of social media use relate to mental health. The dataset includes social media variables (average daily use, most-used platforms, conflict caused by social media, and self-perceived addiction) and demographic characteristics (age, gender, education level, and country of residence). The overall objective is to identify harmful social media use patterns that are associated with worse mental health that ultimately deteriorate a students' performance and overall health.
