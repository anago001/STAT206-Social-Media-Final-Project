## Project Description
This project analyzed the student social media dataset from Kaggle to evaluate how patterns of social media use relate to mental health. The dataset included social media variables (`average daily use,` `most-used platforms,` `conflict caused by social media,` and `self-perceived addiction`) and demographic characteristics (`age,` `gender,` `education level,` and `country of residence`). The overall objective was to identify harmful social media use patterns that were potentially associated with worse mental health outcomes, ultimately deteriorating a students' academic performance and overall health.
